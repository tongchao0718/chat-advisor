# Chat Advisor - 全场景聊天顾问

> 一套完整的聊天分析方法论，帮助你读懂聊天潜台词、判断关系阶段、生成高质量回复。

## 📋 这是什么？

Chat Advisor 是一个 **AI Agent 技能（Skill）**，提供：

- **方法论层**：信号验证、表达DNA分析、关系温度判断、回复生成、纪律系统
- **知识库层**：20个心理学/关系学文档 + 23个实战指南

适用于恋爱关系、职场沟通、朋友社交、家庭关系等全场景。

## 🎯 核心能力

### 方法论（SKILL.md）

- **信号三重验证**：跨场景复现 × 预测力 × 区分度
- **表达DNA基线**：7个维度量化追踪对方的表达风格
- **矛盾处理原则**：时间性/场景性/本质性矛盾的分类处理
- **关系温度四阶段**：降温期 → 回暖期 → 升温期 → 巅峰期
- **四维合一回复生成**：情景 × 对方心情 × 我的心情 × 关系状态
- **关心的三层表达**：叮嘱式 → 判断式 → 并排分析式
- **纪律系统**：七类禁发、发前三问、焦虑自救、说错话止损
- **场景剧本库**：恋爱/职场/友情/家庭四大场景

## 🚀 如何使用？

### 作为 Hermes Agent 技能

1. 将整个 `chat-advisor` 目录复制到你的 Hermes skills 目录：
   ```
   ~/.hermes/skills/research/chat-advisor/
   ```

2. 重启 Hermes Agent，技能会自动加载

3. 在对话中分享聊天截图或描述场景，Agent 会使用此方法论进行分析

### 首次使用

Agent 会引导你建立档案：
- 你的基本信息和沟通风格
- 分析对象的信息
- 关系背景和当前状态
- 你的诉求

之后每次分享聊天内容，Agent 会：
- 提取关键信号并验证
- 判断关系温度阶段
- 给出读数分析
- 生成可复制的回复建议

## 📖 使用示例

**你分享**：
> 她今天主动给我发了张工作截图，说"这个好烦啊"

**Agent 分析**：
> 📊 **读数**：
> - 信号验证：主动分享工作烦恼 ✓ 跨场景复现（上周也分享过）✓ 预测力 ✓ 区分度 ✓ → **核心信号**
> - 关系温度：回暖期（主动分享+示弱）
> 
> 💬 **建议回复**：
> "看起来是那种改了八遍还不让过的文档"
> 
> **原理**：并排分析式关心，和她一起吐槽，不说"别太累了"这种叮嘱式废话
